## 3. Governed Mutation Evaluation & Equivalent-Mutant Rules (`TEST-LOCAL-511`)

Under `POL-INT-01`, every required mutation definition (`1`..`11` above) MUST be independently evaluated via an isolated single-fault patch over the unmodified passing control, and every non-equivalent mutant MUST be killed by an approved oracle:

1. **Valid vs. Invalid Kills:** Valid mutation kills require behavioral test assertion failures (or an explicitly authorized structural invariant oracle such as the zero-compression/`Inflater` source scan alongside runtime raster length checks for mutant `10`). Compilation errors, missing dependencies, unexecuted/skipped suites, infrastructure errors, and unauthorized process crashes MUST NOT be counted as valid mutation kills. Combined multi-fault mutations (such as removing upstream `1..1024` dimension guards alongside mutant `5`) are strictly prohibited and MUST NOT be counted as single-fault kills.
2. **Scoped Equivalent-Mutant Acceptance Criteria (Mutant 5 Only — No Blanket Waiver):** An `EQUIVALENT` classification is permitted solely for specifically proven guarded constructs — here mutant `5` (`(width.toInt() * height.toInt()).toLong()` inside `HoslamFrameDecoder.decodeMap` while `1..1024` unsigned dimension bounds remain active) — and ONLY when ALL five conditions hold and are recorded:
   1. **Exact Single-Fault Documentation:** The isolated single-fault diff is precisely documented as a unified patch without removing unrelated guards or injecting secondary faults.
   2. **Domain & Reachable-Path Proof:** Semantic equivalence between the original implementation and the isolated mutant is proved across the relevant reachable input domain (`1 <= width <= 1024`, `1 <= height <= 1024`, `1 <= width * height <= 1_048_576 < Int.MAX_VALUE`) and for all rejected inputs returning before multiplication.
   3. **Reproducible Executable Evidence:** Exhaustive bounded-domain execution checks plus compiled isolated unit-test runs on both the unmodified control and strict single-fault mutant establish unchanged behavior across reachable paths.
   4. **Independent Reviewer Sign-Off:** An independent reviewer verifies the mathematical/bytecode equivalence proof and all supporting executable artifacts.
   5. **Supplemental Guard-Bypass Probe (`M05-GUARD`):** When equivalence results from an upstream guard, a supplemental single-fault guard-bypass probe (`M05-GUARD`, bypassing `MAX_DIMENSION` upper bounds while preserving `Long` multiplication and `MAX_PIXEL_COUNT`) is executed separately and deterministically killed by behavioral test assertions, proving the protecting guard itself is enforced.
3. **Fail-Closed Default:** Until Conditions `1`–`5` are satisfied, independently verified, and formally approved per `POL-INT-01` §3.2, `TEST-LOCAL-511` remains `BLOCKED / PENDING_APPROVAL` and MUST NOT be marked `PASS`.
