### REQ-LOCAL-502: HOSLAM TCP Frame Envelope, Modular Checksum & Stream State Machine
*(Workstream: `T3` — Binary Framing & Fail-Closed Parsing | Crosswalk: `LF-003`, `P-002`..`P-004`, `P-010`, `NF-003`, `NF-008`)*

A pure-JVM stream framer (`L02A`) must reassemble HOSLAM TCP frames across arbitrary byte-stream chunks, verify exact magic headers, bounded unsigned `Long` lengths, and unsigned byte-sum checksums, and fail closed without resync heuristics or socket/lifecycle coupling.

- **AC-502.1:** *(Stage Owner: `Task 2` / `L02A`)* Incremental `HoslamStreamFramer` copies needed bytes out of caller chunks (input chunk ownership stays with caller), recognizes strictly three 8-byte magic prefixes (`68 6f 73 6c 6d 61 70 00` for `MAP`, `68 6f 73 6c 63 61 63 00` for `AUX`, `68 6f 73 6c 74 72 61 6a` for `TRAJECTORY`), decodes u32 little-endian total length at offset `8` using per-byte `(b.toLong() and 0xFFL)` shifts before any `Int` cast or payload allocation (`16L <= length <= 2_097_152L`), verifies trailing 4-byte u32 LE checksum equals `sum(frame[0 .. len-5].toLong() and 0xFFL) mod 2^32`, emits ordered `RawHoslamFrame` values invariant across `1`-byte, `7`-byte, `12`-byte, every split point, seeded random chunks, and concatenated multi-frame buffers, and holds at most 1 active `<= 2 MiB` frame buffer between `feed()` calls.
- **AC-502.2:** *(Stage Owner: `Task 2` / `L02A`)* Envelope failures emit typed `LocalCodecError` values with 0-based session-relative `Long` `frameStartOffset` and zero raw payload bytes under deterministic precedence (`12`-byte header collection -> `InvalidMagic` -> `InvalidLength` for `< 16L` or strictly `FrameTooLarge` for `> 2_097_152L` including `0x80000010L` and `0xFFFFFFFFL` -> `TruncatedFrame` on mid-header/mid-body EOF -> `InvalidChecksum`), preserving previously validated frames in the same chunk, entering terminal failure state (emitting zero partial, failed, or trailing frames thereafter), returning non-error `EndOfStream` when `finish()` is called cleanly at a frame boundary, and resetting cleanly via `reset()` across sessions.

### REQ-LOCAL-503: Raw Unsigned 8-Bit HOSLAM Raster Decoder & Stage 0 ZLIB Correction
*(Workstream: `T3` — Raw Grayscale Raster Decoding | Crosswalk: `LF-003`, `P-005`..`P-007`, `NF-006`, `NF-008`, `ADR-L004`)*

Recognized `hoslmap\0` frames (`L02B`) must validate type-specific dimensions and alignment/padding rules and decode strictly as uncompressed raw unsigned 8-bit grayscale rasters starting at offset 36 without ZLIB decompression, correcting the Stage 0 ZLIB assumption.

- **AC-503.1:** *(Stage Owner: `Task 3` / `L02B`)* `HoslamFrameDecoder` validates checksum-verified `MAP` `RawHoslamFrame` inputs strictly in deterministic order: (1) `totalLength < 40` -> `UnsupportedLayout(frameStartOffset, MAP, "MAP_LENGTH_BELOW_40")`; (2) u32 LE `width` (`W`) at offset `28` and `height` (`H`) at offset `32` via `(b.toLong() and 0xFFL)` outside `1L..1024L` or `W * H > 1_048_576L` -> `InvalidDimensions`; (3) `end = 36L + W * H`, `aligned = (end + 3L) and 3L.inv()`, `totalLength.toLong() != aligned + 4L` -> `UnsupportedLayout(frameStartOffset, MAP, "MAP_LENGTH_LAYOUT_MISMATCH")`; (4) any padding byte in `[end .. aligned - 1]` != `0x00` -> `InvalidPadding` (supporting valid pad lengths `0`, `1`, `2`, and `3`).
- **AC-503.2:** *(Stage Owner: `Task 3` / `L02B`)* Raster payload `frame[36 .. 36 + W * H - 1]` decodes directly as row-major unsigned 8-bit grayscale (`pixel(x, y) = byte[y * W + x].toInt() and 0xFF`, rendered as `RGBA = (v, v, v, 255)` with top-left display origin only, zero flipping/transposition/metric inference/quantization), using **zero `java.util.zip.Inflater` / ZLIB / LZ4 calls** (leaving cloud `REG-04` ZLIB isolated as a separate unverified cloud path); metadata bytes `12..27` remain opaque; pure domain `RasterSnapshot` enforces defensive `copyOf()` ownership on construction and `copyPixels()` alongside custom content-based `equals`/`hashCode` and redacted `toString()`, matching synthetic vectors (`valid_mixed.bin` + negative vectors), killing isolated temporary-workspace mutants, and (when owner supplies private capture `E-002` locally) matching `230` frames (`77`/`77`/`76`, `28` `278x213`, `49` `278x214`, `73` unique raster SHA-256 digests).
